# ACCELERATE POLAND homepage

Responsive React/Vite homepage for the ACCELERATE POLAND initiative. This project is intentionally separate from the preserved visual-direction prototype at `http://127.0.0.1:4174/`.

## Included

- Approved ACCELERATE POLAND logo, favicon, palette, typography, spacing and component language.
- Responsive institutional navigation with active-section tracking and a mobile menu.
- Modular hero derived from the approved visual direction.
- Initiative, six-pillar vision, programmes, V2V acceleration, audiences, grants, partners, contact and footer sections.
- Artzzs-inspired directional scroll reveals and staged card hover states using GSAP.
- Lenis smooth scrolling with a reduced-motion fallback.
- Real, licence-traceable Polish photography documented in `public/assets/PHOTOGRAPHY_MANIFEST.md`.
- Working V2V stage controls, grant search/filtering and demonstrator contact-form completion state.

## Local preview

```bash
npm run dev -- --host 127.0.0.1 --port 4181
```

## Verification
